# russisch_vokabel



lkey.py is for training the russian keyboard

very basic implementation. The idea is to type on a german keyboard and translate the pressed key into a russian one.

green background for right keypress and red background for typing the wrong key

ruvocab.py is a basic vocabular trainer. It supports accents on russian vocals (implemented with wx, tkinter does not support the accents )


with shift arrow left a russion vowel gets an additional accent

otherwise by preceeding '#' to a newly typed vowel an accent is set.


also very basic implementation. But it does the job.
